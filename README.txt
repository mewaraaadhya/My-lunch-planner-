MY LUNCH PLANNER — COMPLETE WEBSITE / INSTALLABLE WEB APP

Included features:
- Weekly vegetarian Indian lunch menu, with day selection and shuffle
- Breakfast, lunch, and dinner recipes
- Ingredient checklists and cooking instructions
- Pantry ingredient selector and custom ingredient entry
- Recipe matches ranked by selected ingredients
- Cute pastel, responsive design for mobile and desktop
- SEO title, description, social metadata, robots.txt and sitemap.xml
- PWA manifest, icon and service worker for installability/offline caching

IMPORTANT:
The website is built as a static Progressive Web App (PWA). It is not a native Android APK and is not automatically published online. It needs a public HTTPS URL before anyone can use it on Google or install it.

FREE PUBLISHING WITH GITHUB PAGES:
1. Extract this ZIP.
2. Visit https://github.com/ and sign in/create an account.
3. Create a PUBLIC repository named my-lunch-planner.
4. Upload the files in this folder to the repository root: index.html, manifest.json, service-worker.js, icon.svg, robots.txt, sitemap.xml, README.txt.
5. Open repository Settings → Pages.
6. Under Build and deployment choose Deploy from a branch; select main and /(root); Save.
7. Wait for GitHub Pages to provide a URL, usually https://YOUR-USERNAME.github.io/my-lunch-planner/ .
8. Open that URL in Chrome on Android. Tap ⋮ → Install app or Add to Home screen.

GOOGLE SEARCH:
- Google indexing and ranking cannot be guaranteed. A new website may take days or longer to appear, and searching the exact name may not immediately show it.
- For better discoverability, use a memorable custom domain if possible, and update the sitemap.xml and robots.txt URLs to your real published address.
- In Google Search Console (https://search.google.com/search-console/about), add/verify the site and submit the sitemap URL.
- Keep useful original recipes, clear page text and a descriptive site title. Do not expect the words “My Lunch Planner” alone to guarantee the first result.
- This static site currently stores pantry selections only in the page session; it does not have accounts or cloud storage.
